# The King James Bible, 1611, in Akoma Ntoso

80 books, 1,355 chapters and 36,702 verses, one Akoma Ntoso file per book, styled by CSS to suggest the 1611 printing. Open `index.html`, or any `.xml` file through a web server.

## Sources

- Text: [aruljohn/Bible-kjv-1611](https://github.com/aruljohn/Bible-kjv-1611). Not checked against a scan of the 1611 printing.
- Title page: reset from the 1611 title page wording.

## Not included

The Rest of Esther (absent from the source), the front matter, the chapter summaries and the marginal notes. Book names are the source's modern names.

## Status

Generated by Claude for Grant Vergottini. Not an authoritative text. The XML validates against the Akoma Ntoso 2.0 schema.

## Fonts

`kjv-gotisch.woff2` is a modified subset of Grenze Gotisch, with a long s added as a contextual alternate. `kjv-roman.woff2` is IM Fell Double Pica. `kjv-initials.woff2` is UnifrakturCook. See `FONT-LICENSES.md`.
